## Neuromuscular disorders

CDC's immunization decision-support logic (CDSi) has a patient condition "Neuromuscular disorders" (CDSi observation 285) that changes vaccine recommendations. A clinic system has only the ICD-10-CM code on the problem list. For each code below, does a patient carrying that code meet this condition for the purpose of the ACIP recommendations that use it? Answer yes or no for every code, with the reason and a source. The tentative answer and its reason (or the doubt) are given after each code.

- A05.1 Botulism food poisoning: tentative no; doubt: botulism is an acute neuromuscular junction poisoning that resolves
- G10 Huntington's disease: tentative no; doubt: Huntington disease is a central nervous system disorder
- G54.0 Brachial plexus disorders: tentative no; doubt: brachial plexus disorder is focal and usually does not affect respiratory or bulbar muscles
- G60.2 Neuropathy in association with hereditary ataxia: tentative yes; doubt: hereditary neuropathy with ataxia: a peripheral nerve disorder, but the ataxia is central
- G60.8 Other hereditary and idiopathic neuropathies: tentative yes; doubt: hereditary and idiopathic neuropathies are peripheral nerve disorders; includes purely sensory forms
- G60.9 Hereditary and idiopathic neuropathy, unspecified: tentative yes; doubt: hereditary or idiopathic neuropathy, unspecified; includes purely sensory forms
- G62.89 Other specified polyneuropathies: tentative yes; doubt: other polyneuropathies are peripheral nerve disorders; severity unknown
- G62.9 Polyneuropathy, unspecified: tentative no; doubt: polyneuropathy, unspecified is mostly diabetic or toxic sensory neuropathy without weakness
- G72.0 Drug-induced myopathy: tentative no; doubt: drug-induced myopathy is usually reversible when the drug stops
- G73.7 Myopathy in diseases classified elsewhere: tentative yes; doubt: myopathy secondary to another disease is a muscle disorder
- G83.0 Diplegia of upper limbs: tentative no; doubt: upper-limb diplegia is a finding; its cause may be central or neuromuscular
- J96.10 Chronic respiratory failure, unspecified whether with hypoxia or hypercapnia: tentative no; doubt: chronic respiratory failure has many causes; neuromuscular is one
- J99 Respiratory disorders in diseases classified elsewhere: tentative no; doubt: respiratory disorder in a disease classified elsewhere; the disease may be neuromuscular but is not named
- M41.40 Neuromuscular scoliosis, site unspecified: tentative yes; doubt: neuromuscular scoliosis implies an underlying neuromuscular disorder, which is not named

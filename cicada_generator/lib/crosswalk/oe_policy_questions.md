## DiGeorge syndrome in CDC's own coded data

CDC's immunization decision-support logic (CDSi) supporting data lists SNOMED CT 77128003 "DiGeorge sequence" as a code for both "T-lymphocyte [cell-mediated and humoral] - Complete defects" (CDSi observation 147; examples: SCID, complete DiGeorge syndrome) and "T-lymphocyte [cell-mediated and humoral] - Partial defects" (CDSi observation 148; examples: most patients with DiGeorge syndrome, Wiskott-Aldrich syndrome, ataxia-telangiectasia). Taken as written, a patient whose chart carries only that SNOMED code meets the complete-defect condition as well as the partial one, and is forecast the same as a SCID patient.

For the ICD-10-CM code D82.1 "Di George's syndrome" you advised partial defects only, because a complete defect needs immunologic evidence the code does not carry.

Should a chart record of SNOMED CT 77128003 alone also count as partial defects only, with the complete-defect condition left to a clinician who has the immunologic evidence? Or is CDC's listing under both conditions intended, and which vaccine recommendations would differ between the two readings? Tentative: partial only, for the same reason as D82.1; CDC's listing under both says the concept can be either, not that every patient has both. Give the reason and a source.
